Educational Calculation Breakdown

Mathematical derivation following IPv4 RFC 791 principles
Step 1

Calculate Original Payload

Subtract the standard 20-byte IPv4 header from the total packet size:

Payload = Packet Size - 20 = 4000 - 20 = 3,980 Bytes
Step 2

Max Payload & 8-Byte Alignment

Non-final fragment payloads must be divisible by 8 because the 13-bit Fragment Offset field measures in 8-byte units:

Max Data = ⌊(MTU - 20) / 8⌋ × 8 = ⌊1480 / 8⌋ × 8 = 1,480 Bytes
Step 3

Compute Fragment Offsets

The fragment offset indicates where each fragment's payload begins in the original datagram:

Offset Field = Starting Payload Byte / 8
Step 4

Set More Fragments (MF) Flag

The 1-bit MF flag informs the destination whether additional fragments are incoming for datagram reassembly:

MF = 1 (Intermediate fragments) • MF = 0 (Last fragment)
